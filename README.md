# 🌱 EcoSort

올바른 분리배출 방법을 쉽고 빠르게 검색하고,
환경 상식과 퀴즈를 통해 환경 보호를 학습할 수 있는 웹 서비스입니다.

---

## ✨ 주요 기능

- 🔍 품목명 / 별칭 / 태그 검색
- 🤖 오타 자동 교정(Fuzzy Search)
- 📂 카테고리 검색
- ✨ 검색 자동완성
- 🕒 최근 검색
- ⭐ 즐겨찾기
- 🌱 오늘의 환경 상식
- 🧠 환경 퀴즈
- 🏆 배지 시스템
- 🌍 Eco Level
- 📚 환경 도감

---

## 🛠 기술 스택

- HTML5
- CSS3
- JavaScript (ES6)
- Node.js
- Express
- SQLite
- GitHub
- Render
